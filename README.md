A tiny Python program that writes one fortune-cookie line for a software developer to `/output/entry.txt`: a single line of at most 120 characters in the voice of a fortune slip — wisdom about legacy code that turns, on a second read, into a note from your own past self. The line was picked by drafting fourteen candidates and duelling them pairwise on the bounty judge's own criteria — fortune-cookie wisdom first, then the single-breath balance, how true it rings about a developer's day of bugs, reviews, deploys and estimates, the freshness of its turn, and the quiet double meaning it leaves behind. The drafts and duels are kept in `candidates.md`.

## Run it

```sh
python3 main.py
```
